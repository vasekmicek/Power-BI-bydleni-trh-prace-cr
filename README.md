# Bydlení a trh práce v krajích ČR

Power BI projekt zaměřený na vývoj a regionální rozdíly v oblasti bydlení a trhu práce v České republice v letech 2019–2025.

## Obsah reportu

Report je rozdělen do čtyř hlavních částí:

### Nemovitosti/mzdy
Porovnání vývoje cen bytů a rodinných domů s vývojem průměrných mezd.  
Součástí je také ukazatel dostupnosti bydlení vyjádřený počtem průměrných měsíčních mezd potřebných na 1 m² nemovitosti.

### Výstavba/cena bytů
Porovnání vývoje průměrných cen bytů s počtem dokončených bytů v jednotlivých letech.

### Mzdy/nezaměstnanost
Vývoj průměrných mezd a nezaměstnanosti v čase.  
Součástí je také porovnání průměrných mezd mužů a žen.

### Porovnání krajů
Srovnání jednotlivých krajů podle:
- průměrné mzdy,
- míry nezaměstnanosti,
- dostupnosti bydlení.

## Interaktivita

Report umožňuje filtrovat data podle období a krajů. Mezi jednotlivými částmi reportu lze přecházet pomocí navigačních prvků.

## Použité nástroje

- Power BI
- Power Query
- DAX
